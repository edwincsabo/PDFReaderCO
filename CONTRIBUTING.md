# Contribuir / Contributing

Español: antes de enviar cambios, lee [LICENSE](LICENSE). Las contribuciones
originales se aportan bajo PolyForm Noncommercial 1.0.0. Puedes informar errores
y proponer mejoras mediante Issues; incluye pasos para reproducirlos, versión
y un documento sintético si hace falta. No publiques claves API, datos personales
ni documentos de terceros sin permiso. Ejecuta `npm test` y `npm run build` para
cambios de código; añade comprobaciones de interfaz solo para los flujos afectados.

English: read [LICENSE](LICENSE) before contributing. Original contributions
are submitted under PolyForm Noncommercial 1.0.0. Use Issues to report bugs and
suggest improvements; include reproduction steps, version and a synthetic sample
when needed. Do not publish API keys, personal data or third-party documents
without permission. Run `npm test` and `npm run build` for code changes; run UI
checks for the affected workflows.
